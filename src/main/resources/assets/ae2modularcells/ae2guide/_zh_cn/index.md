# AE2 模块化能量单元

AE2 的附属模组，把能源元件做成可以拼合的模块方块。

把它们实心摆成立方体（3×3×3 至 16×16×16，等级可混拼），整段结构就是你 ME 网络上的一份能量存储，模块方块的任意一面都能接。
