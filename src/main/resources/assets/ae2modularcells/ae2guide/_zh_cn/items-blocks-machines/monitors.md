# 监控器

两台只显示、不产出的面板，拼进立方体时算结构件——它们参与成型判定，但不进容量与速率的求和。所以拼进去既不会破坏结构，也不会虚报账目。

## 能量监控器

正面显示整段的储能百分比，居中一行。

## 能量流量监控器

正面中间是 FE 图标，读数压在下沿：整段近一秒的平均吞吐（AE/t）。装了 Applied Flux 时这枚图标直接用它的那张「FE」，没装就用本模组自带的图标。

瞬时输入速率不上正面。它逐 tick 抖，方块正面又小，挤两行反而看不清「这东西在以多大功率进食」——要看瞬时值去管理终端。

## 成型前后

未成型时是一台独立的监控器：正面是它自己的面板，五个侧面是整块素面（与模块未成型同一口径，不收边）——那时它还没接进任何结构，没有可监控的对象。

成型后正面换上基础面板，再叠三层状态光板。那三张是同一块面板的三个互补图层（中间填充、四个角、外框），必须叠在一起才拼得出一块完整面板；颜色取自 AE2 默认涂色的三档明暗，**不随储能变化**。五个侧面改用另一套底色，并按连接情况收边：贴着邻块的一侧没边框，露在外面的一侧补边框，两条边相遇的角补角贴图——与模块成型后的收边同一套规则。

## 储能档位

档位分五级（0% / 25% / 50% / 75% / 100%），由核心写进方块状态，**只作记录，不参与正面外观**。切换要连续两次采样都落在新档才认；否则比例在档边界上抖一下就会反复写状态，而每一次写状态都会**重置客户端的挖掘进度**——这层去抖就是为它存在的。

## 读数从哪来

核心每 20 tick 算一次整段的储能比例与输入均值，写进监控器的方块实体，再由方块实体同步给客户端。监控器自己没有 ticker，也没有网格节点：整段的账目只挂在核心那一份。

它也不存能量，但玩家会把线接在它上面，FE 能力原样转交给核心——换算比例与「只进不出」的口径只在核心那一处写，这里不复制第二份。
