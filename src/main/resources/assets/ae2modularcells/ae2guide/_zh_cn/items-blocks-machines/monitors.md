# 监控器

两台只显示、不产出的面板。拼进立方体时它们算结构件：参与成型判定，但不增加容量或速率，所以拼进去既不会破坏结构，也不会让读数虚高。

监控器只是结构件，不持有结构的账目，所以一个结构里至少要有一块模块——清一色监控器不算成型。核心由模块担任，不必挑位置：布局序里的第一块模块就是它。

## 能量监控器

正面显示结构的储能百分比，居中一行。

## 能量流量监控器

正面中间是 FE 图标，读数压在下沿：结构近一秒的平均吞吐（AE/t）。装了 Applied Flux 时这枚图标直接用它的那张「FE」，没装就用本模组自带的图标。

瞬时输入速率不上正面。它逐 tick 抖，方块正面又小，挤两行反而看不清「这东西在以多大功率进食」。想看瞬时值，去管理终端。

## 成型前后

未成型时它就是一台独立的监控器：正面是它自己的面板，五个侧面是整块素面，不带边框。那时它还没接进任何结构，没有可监控的对象。

成型后正面换上基础面板，颜色取自 AE2 默认涂色的三档明暗，不随储能变化。五个侧面改用另一套底色，并按连接情况收边：贴着邻块的一侧没边框，露在外面的一侧补边框，两条边相遇的角补角贴图。

## 储能档位

档位分五级（0% / 25% / 50% / 75% / 100%）。核心会把它记下来，但它不影响正面外观。切换要连续两次采样都落在新档才认，否则比例在档边界上抖一下就会反复刷新，而每刷新一次，客户端的挖掘进度就会重置。

## 读数从哪来

核心每 20 tick 算一次结构的储能比例与输入均值，写进监控器的方块实体，再由方块实体同步给客户端。监控器自己没有 ticker，也没有网格节点。

它也不存能量，但玩家会把线接在它上面，所以它的 FE 能力原样转交给核心。
