# Blank Energy Unit

A casing waiting for work — the crafting intermediate for all three module tiers.

It stores nothing, never forms, and does not connect to the ME network. Placing it inside a cube accomplishes nothing: structures only recognise module blocks, so wherever it ends up it is just another wall. Take it to a crafting grid.
